Current code diagnosis: bodyScissors uses seated attacker, flat supine defender; two independent ankle targets on near/far hip points (torso .15, y ±9), with no actual ankle-to-ankle lock. Current staging/contacts do not establish a closed encirclement. Recommendation: rebuild a single side-lying locked pose first, hips close, far leg behind receiver, near leg over waist, ankles visibly crossed; subtle squeeze and receiver struggle, then author entry/release. Avoid a few angle tweaks to current arrangement. Arm control can follow once leg closure is established. Grounded head scissors: separate pose around head, head supported between thighs, near/far leg depth clear and ankles crossed; not a flying headscissors takedown. Narrower target likely makes silhouette easier than body scissors, but head/face occlusion needs inspection.

Existing leg IK/layering supports the needed structure; use pose/contacts first, assess any painted limb variant only if source art fails the overlap. No global rig rewrite justified by evidence. Next implementation is body scissors locked pose, then entry/hold/release, then grounded head scissors. Accepted recovery/escape/kip-up and stance work preserved.
