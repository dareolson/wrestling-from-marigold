# Thesz canonical-v2 — Pass B profile-v2 candidate

This is a versioned source-art and articulation checkpoint. It does not replace
the approved Pass-A v3 master or the manifest-bound Pass-B bank.

## Outputs

- `parts/`: individual transparent profile sources.
- `profile-v2-parts-contact-sheet.png`: source-parts review board.
- `profile-v2-neutral-assembly.png`: neutral depth/registration proof.
- `profile-v2-articulation-proof.png`: chained moved-limb proof.
- `parts-index.json`: source component bounds and reuse policy.
- `sources/`: retained chroma and alpha generation sources.

The visible black trunks are permanently attached to `torso-trunks.png`.
Profile depth is `pelvisUnderlay -> far leg -> torso+trunks -> near leg ->
arms`. No horizontal mirroring is used for the upper arm, thigh, shin, or
boots. Near/outward-back-of-hand and far/inward-palm forearm-hand sources are
separate authored images.

## Generation mode

Built-in image generation, identity-preserving referenced generation followed
by one precise torso-silhouette edit. References were the strict-profile regen
and the approved canonical Lou likeness. Prompts required a complete armless
torso with attached trunks, a reusable same-facing upper arm and leg set, two
distinct forearm-hand surfaces, complete hidden overlap paint, and two
right-facing boots. Chroma removal, component extraction and proofs are
deterministic local Node scripts.
