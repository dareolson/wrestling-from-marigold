Source Anchor Editor — per-part compatibility tool

Artist-approved anchors are authoritative. This editor handles individual part PNGs and the v1-style base manifest; it does not edit the canonical v2 multi-view sheet or its view overrides. Use the canonical v2 guide plus its layered source/manifest for new Thesz work. Crosshairs and overlap bands are never baked into clean art. Hidden attachment bands use continuous fill/shading—no bevel, contour ring, rim highlight, or cutoff line.

Click the art to place the active anchor. Drag an existing crosshair to refine it. Arrow keys move it one export pixel; Shift+arrow moves ten.
